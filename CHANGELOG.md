# Changelog

## v0.9.0-beta (2025-XX-XX)

First public beta release.

### Features
- Live TV with EPG (Electronic Program Guide)
- Movies & Series browsing
- MPV-powered playback (HEVC/H.265, 4K, hardware acceleration)
- HLS.js browser fallback player
- Multi-playlist support (M3U & Xtream Codes)
- Multi-profile system
- OpenSubtitles integration (auto-download + manual search)
- VOD downloads with resume support
- Remote control via local network (phone/tablet)
- Trakt scrobbling
- Customizable UI (themes, accent colors, layout)
- Full keyboard shortcut support
- Secure credential storage (OS keychain)
- Live TV recording (stream capture)
- Category pinning with drag-to-reorder
- Configurable live TV default view

### Known Issues
- Some IPTV servers may timeout on large file downloads (auto-retry handles most cases)
- Unsigned Windows binary may trigger antivirus false positives
